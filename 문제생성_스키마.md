# CodeFill 문제 데이터 스키마 v2 (최종)

## 테이블 스키마

```sql
-- 빈칸
CREATE TABLE problems_blank (
    original_id VARCHAR(50),
    language VARCHAR(20),
    code_template TEXT,    -- "_0_", "_1_" 형식
    answers TEXT[],
    PRIMARY KEY (original_id, language)
);

-- 퍼즐
CREATE TABLE problems_puzzle (
    original_id VARCHAR(50),
    language VARCHAR(20),
    fixed_start TEXT,      -- 보일러플레이트 (고정 표시)
    fixed_end TEXT,        -- 닫는 부분 (고정 표시)
    blocks JSONB,          -- [{id, code}] id 순서 = 정답
    PRIMARY KEY (original_id, language)
);

-- 1대1 대화형
CREATE TABLE problems_guided (
    original_id VARCHAR(50),
    language VARCHAR(20),
    concepts TEXT[],
    flow TEXT[],
    checkpoints TEXT[],
    PRIMARY KEY (original_id, language)
);
```

## Puzzle 구조

```json
{
  "original_id": "baekjoon_1001",
  "language": "java",
  "fixed_start": "import java.util.Scanner;\npublic class Main {\n    public static void main(String[] args) {",
  "fixed_end": "    }\n}",
  "blocks": [
    {"id": 1, "code": "Scanner sc = new Scanner(System.in);"},
    {"id": 2, "code": "int a = sc.nextInt();"},
    {"id": 3, "code": "int b = sc.nextInt();"},
    {"id": 4, "code": "System.out.println(a - b);"}
  ]
}
```

### 규칙
- **id 순서 = 정답 순서** (order 필드 불필요)
- **fixed_start/end**: 보일러플레이트는 화면에 고정 표시
- **blocks만 퍼즐**: 사용자가 순서 맞추기
- **의미있는 단위로 합침**: `}` 단독 블록 없음, for문은 내용 포함해서 하나로

### 프론트 렌더링

```
┌─────────────────────────────────────┐
│ import java.util.Scanner;           │  ← fixed_start (회색, 고정)
│ public class Main {                 │
│   public static void main(...) {    │
├─────────────────────────────────────┤
│  [드래그 가능한 블록들 - 섞어서]      │  ← blocks (퍼즐 영역)
│  ┌─────────────────────────────┐   │
│  │ int b = sc.nextInt();       │   │
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │ Scanner sc = new Scanner... │   │
│  └─────────────────────────────┘   │
│  ...                               │
├─────────────────────────────────────┤
│   }                                 │  ← fixed_end (회색, 고정)
│ }                                   │
└─────────────────────────────────────┘
```
