# CodeFill Badge Icons - Recraft Prompts
#
# Recraft는 한번에 1개씩만 생성 가능!
# 하지만 같은 스타일/팔레트 설정을 유지하면서 여러 개 생성 가능
#
================================================================================

## Recraft 사용법

### 1단계: 프로젝트 설정
1. recraft.ai 접속 및 로그인
2. 새 프로젝트 생성 (프로젝트 단위로 스타일 유지됨)
3. 프로젝트 이름: "CodeFill Badges" 등

### 2단계: 스타일 설정 (중요!)
1. 좌측 Style 메뉴 클릭
2. "Icon" 또는 "Flat Icon" 선택
3. 또는 "Digital Art" > 심플한 스타일 선택

### 3단계: 컬러 팔레트 설정 (핵심!)
1. 좌측 "Color" 또는 "Palette" 메뉴
2. 카테고리별로 2색 팔레트 설정:
   - 메인색 (희귀도) + 포인트색 (아이콘 특성)
3. 같은 카테고리는 팔레트 유지하며 생성

### 4단계: 프롬프트 입력 & 생성
1. 아래 프롬프트 복사해서 입력
2. Generate 클릭
3. 4개 결과 중 마음에 드는 것 선택
4. SVG로 다운로드

### 5단계: 반복
- 같은 팔레트로 다음 아이콘 생성
- 카테고리 바뀌면 팔레트 변경
