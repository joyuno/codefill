Hint System & Intent Classification

💡 4-Level Hint System

Level 1

방향 제시
"어떤 유형의 문제일까요?"

Level 2

접근법 제시
"~~ 알고리즘을 생각해보세요"

Level 3

구체적 힌트
"1. 먼저 ~~ 2. 그다음 ~~"

Level 4

코드 구조
핵심 부분 (변수명 가림)

🎯 Intent Keywords → Node Routing

힌트, 도움, 막혔 → provide_hint
제출, 정답, 채점 → check_answer
피드백, 어때 → provide_feedback
요약, 정리 → summarize_problem
