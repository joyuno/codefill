🎯 Intent Tool Tool

사용자 메시지의 의도와 액션을 분류합니다.

  • Category: INFO_COLLECTION, DISCOVERY, SOLVING, GENERAL
  • Action: SET_TOPIC, SELECT_PROBLEM, REQUEST_HINT 등
  • Extracted Values: topic, difficulty, language

📋 InfoCollectionGraph Graph

문제 생성에 필요한 정보를 수집합니다.

  • 수집 정보: 주제, 난이도, 언어
  • 대화 방식: Multi-turn + 추천
  • 완료 조건: 3가지 정보 모두 수집

🔍 DiscoveryGraph Graph

RAG 검색 또는 새 문제 생성을 수행합니다.

  • RAG: 시맨틱 검색 (필터 + 벡터)
  • Fallback: CodeGen Agent
  • 문제 유형: Blank, Puzzle, Guided

✨ SolvingGraph Graph

문제 풀이 중 다양한 지원을 제공합니다.

  • Hint Agent: 4단계 점진적 힌트
  • Review Agent: 코드 리뷰 (JSON)
  • Check: Judge0 코드 실행
