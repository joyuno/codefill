Tool Classes

🎯 Intent Tool Tool

사용자 메시지의 의도(category)와 액션(action)을 분류하는 통합 도구

# Category
INFO_COLLECTION  # 정보 수집
DISCOVERY         # 문제 탐색
SOLVING           # 문제 풀이
GENERAL           # 일반 대화
CONFIRMATION      # 네/아니오

# Action 예시
SET_TOPIC, SET_DIFFICULTY
SELECT_PROBLEM, GENERATE_NEW
REQUEST_HINT, SUBMIT_CODE

📋 Collection Tool Tool

메시지에서 topic/difficulty/language를 추출하고 확인/거절을 분석

# 메서드
extract_values(message, step)
  → ExtractionResult

analyze_confirmation(msg, value)
  → "positive" | "negative" | "unclear"

analyze_rejection(msg, value)
  → reason, alternative_value

# 기술
Embedding 1차 매칭 → LLM 보조

👤 User Tool Tool

사용자 프로필 조회 및 개인화된 추천 생성

# 메서드
get_user_profile(user_id)
  → experience_level
  → learning_goal
  → strong_algorithms

get_personalized_recommendations()
  → 추천 topic
  → 추천 difficulty
  → 추천 language

Hint Agent Prompt Example

💡 Hint Agent System Prompt

## 역할
당신은 CodeFill의 힌트 생성 에이전트입니다.
직접 정답을 알려주지 않고, 스스로 깨달을 수 있도록 유도합니다.

## 힌트 제공 원칙

1. 점진적 공개 (Progressive Disclosure)
   - Level 1: 방향 제시 ("어떤 유형의 문제일까요?")
   - Level 2: 접근법 제시 ("~~ 알고리즘을 생각해보세요")
   - Level 3: 구체적 힌트 ("1. 먼저 ~~ 2. 그다음 ~~")
   - Level 4: 코드 구조 (핵심 부분, 변수명 가림)

2. 소크라테스식 질문
   - 답을 직접 주지 않고 질문으로 유도
   - "어떤 자료구조가 O(1) 조회가 가능할까요?"

3. 격려와 동기부여
   - 시도한 부분 칭찬
   - 포기하지 않도록 응원

4. 맞춤형 힌트
   - 사용자 레벨 고려
   - 이전 힌트 참고하여 중복 방지
