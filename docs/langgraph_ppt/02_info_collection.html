Nodes & Conditional Edge

📥 parse_input

메시지 파싱, 값 추출, 긍정/부정 분석

출력: extracted_value, is_question, is_positive_response

CollectionTool

❓ handle_question

질문 처리, LLM 추천 생성, 확인 대기

출력: suggested_value, awaiting_confirmation

gpt-4o-mini

✅ confirm_value

값 확정, State 업데이트, 다음 step 이동

출력: topic/difficulty/language 확정

State Update

🎯 complete

모든 정보 수집 완료, DiscoveryGraph로 이동

출력: is_complete=True, route_to="discovery"

Route Signal

🔀 Conditional Edge: route_after_parse

is_question=True → handle_question (LLM 추천)
needs_reconfirmation → handle_question (재확인)
current_step=complete → complete (수집 완료)
extracted_value 존재 → confirm_value (값 확정)

📦 CollectionState (핵심 필드)

message: str               # 사용자 메시지
topic: Optional[str]       # DP, 그래프, 정렬 등
difficulty: Optional[str]  # easy~very_hard, 티어
language: Optional[str]    # python, java, cpp
current_step: str         # topic→difficulty→language→complete
is_question: bool         # 사용자가 질문했는지
extracted_value: str     # 추출된 값
suggested_value: str     # LLM 추천 값
awaiting_confirmation: bool # 네/아니오 대기
is_complete: bool        # 수집 완료 여부
