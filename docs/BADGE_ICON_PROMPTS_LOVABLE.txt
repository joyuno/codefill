## 카테고리별 분할 요청 (한번에 안될 경우)

### 요청 1: 배지 시스템 기본 구조
```
게이미피케이션 배지 시스템의 기본 구조를 만들어줘.

1. Badge 타입 정의
   - code, name, description, iconName, rarity, condition

2. 희귀도 색상 시스템
   - common: #CD7F32 (bronze)
   - uncommon: #22C55E (green)
   - rare: #3B82F6 (blue)
   - epic: #A855F7 (purple)
   - legendary: #EAB308 (gold)

3. BadgeCard 컴포넌트
   - 아이콘, 이름, 설명 표시
   - 희귀도별 색상 적용
   - 잠긴 상태 / 획득 상태 구분

4. BadgeGrid 컴포넌트
   - 배지 목록 그리드 표시
```
