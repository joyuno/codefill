===========================================
GUIDED CODE COMPARISON HINT (코드 비교 힌트)
LLM 사용 안 함 - 순수 Python 로직
===========================================

1대1 대화형 문제에서 사용자 코드와 정답 코드를 비교하여
가장 첫 번째 누락/오류 줄의 정답 코드를 제공합니다.

============================================================
설정
============================================================

GUIDED_HINT_CONFIG = {
    "max_hints": 4,           # 최대 힌트 횟수
    "xp_penalty": 5,          # 힌트당 XP 차감 (-5xp)
    "lines_per_hint": 1,      # 힌트당 제공할 줄 수
}

============================================================
핵심 함수: compare_and_get_next_line
============================================================

def compare_and_get_next_line(user_code: str, solution_code: str, hint_count: int) -> dict

입력:
- user_code: 사용자가 작성한 코드
- solution_code: 정답 코드
- hint_count: 현재까지 사용한 힌트 횟수 (0-3)

출력:
{
    "hint_content": "다음 줄 정답 코드",
    "line_number": 줄 번호,
    "hint_count": 사용한 힌트 횟수,
    "remaining_hints": 남은 힌트 횟수,
    "is_last_hint": 마지막 힌트 여부,
    "message": "안내 메시지",
    "xp_penalty": 5  # XP 차감량
}

============================================================
동작 로직
============================================================

1. 힌트 횟수 초과 체크 (hint_count >= 4)
   → "힌트를 모두 사용했습니다." 반환

2. 코드를 줄 단위로 분리 (빈 줄 제외)

3. 사용자 코드가 비어있으면
   → 정답 첫 번째 줄 제공

4. 줄별 비교:
   - 사용자 코드가 더 짧으면 → 다음 줄 제공
   - 줄 내용이 다르면 → 해당 줄의 정답 제공

5. 모든 줄 일치 시
   → "코드가 정답과 일치합니다!" 반환

============================================================
줄 비교 정규화
============================================================

_normalize_line(line: str) -> str

- 앞뒤 공백 제거
- 연속 공백을 단일 공백으로 변환
- 들여쓰기 차이는 무시하고 내용만 비교

============================================================
응답 예시
============================================================

# 첫 번째 힌트 요청 (user_code 비어있음)
{

    "line_number": 1,
    "hint_count": 1,

============================================================
특징
============================================================

1. LLM 호출 없음 → 즉시 응답, 비용 0
2. 최대 4번 힌트 제공
3. 힌트당 -5 XP 차감
4. 정확한 정답 코드 1줄씩 제공 (간접 힌트 아님)
5. 줄 비교 시 공백 정규화로 포맷 차이 무시
